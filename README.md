## Categories

- **SIEM investigations:** Reviewing signals and identifying events that require attention.
- **SOC operations:** Understanding Tier 1 workflows and shift responsibilities.
- **Alert triage:** Assessing alerts, evaluating severity, and prioritizing investigations.
- **Evidence management:** Recording findings and maintaining clear case documentation.
- **Case handling:** Organizing investigation notes and tracking case progress.
- **Incident escalation:** Applying escalation workflows and distinguishing events from incidents.

## Recommended Learning Path

1. Start with **SOC Workflow Snap** and **Tier 1 SOC Shift**.
2. Practice investigating signals with **SIEM Signal Hunt** and **Alert Lens**.
3. Develop triage skills using **Triage Tactics** and **Alert Priorities Unpacked**.
4. Continue with **Severity Sense: Alert Triage Mastery** and **Event or Incident**.
5. Study documentation using **Evidence Chain Notebook** and **Case File Command**.
6. Finish with **Shift Handover Secure** and **Escalation Playbook**.

Follow the prerequisites and instructions on each original lab page.

## How to Use the Labs

1. Select a lab and open its Learn SecByte page.
2. Review the exercise objectives and authorized environment.
3. Follow the instructions to investigate the available signals or case evidence.
4. Document observations, timestamps, severity rationale, and next steps.
5. Practice communicating findings clearly, especially when handing over or escalating a case.

An alert does not automatically confirm an incident. Assess available evidence, business context, potential impact, and uncertainty before recommending escalation.
